# 쎈스 초퍼 (Sense Chopper)

WSNS studio [웨스엔에스 스튜디오]의 웹앱입니다. 학습지나 스캔한 종이 한 장에 그린 여러 그림을 격자에 맞춰 칸마다 잘라 내고, 이름을 붙여 한 번에 저장합니다. 이미지 처리는 모두 브라우저 안에서 하며 서버 · 데이터베이스 · API 키가 없습니다. 무료입니다.

- 서비스 주소: https://osense.github.io/Sense_Chopper/
- 제품 소개: https://wsns.studio/products/sense-chopper/

## 자동 인식 학습지

첫 화면과 01 원본 이미지 패널에서 "이모티콘 만들기" 학습지 견본(A4, 3 × 4칸)을 PDF · PNG로 받을 수 있습니다. 네 모서리에 QR 코드와 같은 방식의 기준 마커가 있어, 다 그린 학습지를 휴대폰으로 비스듬히(돌려서 · 거꾸로도) 찍어 불러오면 마커를 찾아 자동으로 반듯하게 펴고 12칸에 영역을 잡습니다. 왼쪽 위 · 오른쪽 위 · 왼쪽 아래는 파인더 패턴(1:1:3:1:1), 오른쪽 아래는 정렬 패턴(1:1:1:1:1)이라 방향을 알 수 있습니다. 주변 밝기 기준 이진화로 그림자 · 조명 차이에 강하고, 정사각형 배치(QR 코드 등)는 학습지로 보지 않습니다. 인식 결과가 마음에 들지 않으면 "보정 없이 원래 사진 쓰기"로 되돌립니다.

## 포스터 분할 인쇄

이미지를 불러온 뒤 "크게 나눠 인쇄 (포스터)"를 고르면 종이(A4 · A3 · B4 · B5 · 레터)와 가로 장수를 묻고, 세로 장수는 그림 비율로 정합니다. 여백 없는 인쇄가 안 되는 프린터를 기준으로 종이 가장자리(기본 7mm)는 비워 두고, 이웃한 장이 겹칠 오른쪽 · 아래쪽에 풀칠 영역(기본 1cm)을 빗금으로 인쇄합니다. 다음 장은 왼쪽 · 위쪽 점선을 따라 흰 가장자리를 잘라 내고 풀칠 영역 위에 겹쳐 붙이면 그림이 이어집니다. 장마다 200dpi로 그려 PDF로 저장하고(실제 크기 인쇄 설정 포함), 맨 앞에 붙이는 순서 지도와 방법을 넣습니다. 보정 없이 그대로 인쇄하며, 미리 예상 선명도(dpi)를 보여 줍니다.

## 작업 흐름 (4단계 · 질문형 안내)

넓은 화면에서는 작업 공간 맨 위 안내 막대가 단계마다 질문하고(대답 도구 · 이전/다음 포함), 왼쪽 패널에는 그 단계의 실제 설정이 늘 보이며, 캔버스 도구는 한 줄에 모여 있습니다. 휴대폰에서는 캔버스 아래 질문 카드로 바뀌고 세부 설정은 ‘세부 설정 열기’로 엽니다.

1. 불러온 이미지가 반듯한가요? → 기울었으면 기준선 긋기
2. 그림이 가로로 몇 개, 세로로 몇 줄 있나요? → 선을 만들고 그림을 찾아 자동으로 가운데에 맞춤 → 선이 가운데를 지나나요?
3. 자를 영역은 어떤 모습인가요? (칸에 꼭 맞게 · 1:1 · 3:4 · 4:3 · 16:9 · 9:16) → 영역의 크기를 맞춰 주세요
4. 총 N장이 나왔어요. 이제 어떻게 할까요? → 낱장 이미지(ZIP) · 움직이는 GIF · 발표 자료(PPT)


| 단계 | 하는 일 | 주요 파일 |
|---|---|---|
| 1. 불러오기 · 기울기 보정 | 이미지 불러오기, 회전 각도 조절, 선 1개(수평) · 선 4개(원근) 보정 | `app.js`, `rotation.js`, `correction*.js` |
| 2. 가로 · 세로선 맞추기 | 칸 수로 격자 만들기, 가이드 선을 그림 가운데로 끌기 | `guides.js` |
| 3. 자를 영역 다듬기 | 교점마다 생긴 영역을 가운데 점 · 테두리 손잡이로 조절 | `frame-resize.js`, `dimensions.js` |
| 4. 저장하기 | 파일 이름 · 형식 · 크기, 개별 · 선택 · ZIP 저장 | `app.js`, `file-save.js` |

가로 화면(PC · 가로로 든 태블릿, 너비 900px 이상)은 한 화면에 꽉 차는 작업 공간입니다. 단계 탭은 머리글 가운데, 옆 패널은 따로 스크롤되고, 캔버스가 남은 높이를 모두 씁니다. 기울기 · 원근 보정 도구는 옆 패널에 들어갑니다. 세로로 든 태블릿과 휴대폰은 단계 탭이 화면 아래에 고정되고, 휴대폰에서는 캔버스가 위, 설정이 아래로 쌓입니다.

이미지를 불러오기 전 첫 화면은 활용 사례(학습지 · 이모티콘 활동 · 카드뉴스 · 스티커 · 낱말 카드 · 네컷 만화 · 작품 사진 · 스프라이트)를 광고처럼 흘려 보여 주는 배경, 사용법 애니메이션, 예시 학습지 체험 버튼으로 구성됩니다.

## 실행

Node.js 20 이상이 필요합니다. 외부 패키지가 없어 `npm install`은 필요 없습니다.

```sh
npm run dev   # http://localhost:5173
npm test      # 회귀검사
```

원근 보정은 Web Worker를 쓰므로 HTML을 더블 클릭하지 말고 위 방법으로 실행하세요.

## 파일 구조

`dist` 폴더가 원본이자 배포본입니다. 빌드 과정이 없습니다.

| 파일 | 역할 |
|---|---|
| `dist/index.html` | 화면 구성, 머리글(WSNS studio 로고 · 발음 표기), 사용법 창 |
| `dist/style.css` | 전체 스타일 하나로 통합 (WSNS 디자인 토큰, 밝게 · 어둡게, 반응형) |
| `dist/app.js` | 이미지 불러오기, 영역, 미리보기, 출력 크기, PNG · ZIP 저장 |
| `dist/guides.js` | 가이드 선 · 격자, 영역 자동 맞춤 |
| `dist/dimensions.js` | 영역 크기 · 비율 입력 |
| `dist/rotation.js` | 회전 · 캔버스 확장 |
| `dist/navigation.js` | 화면 이동 · 확대 · 터치 |
| `dist/correction.js`, `correction-math.js`, `correction-worker.js` | 기준선 보정 UI · 계산 · 백그라운드 처리 |
| `dist/mobile-steps.js` | 4단계 흐름 (단계 탭, 이전 · 다음, 단계별 보이기) |
| `dist/frame-resize.js` | 영역 가운데 점 · 테두리 손잡이 |
| `dist/file-save.js` | 휴대폰 · 앱 안 브라우저 저장(공유해서 저장) |
| `dist/shell.js` | 밝게 · 어둡게 전환, 사용법 창, 보정 도구 패널 배치, 캔버스 크기 변화 감지 |
| `dist/howto.js` | 사용법 애니메이션: 기준선 긋기 → 수평, 선 하나씩 끌어 맞추기, 모서리로 크기 · 가운데 점으로 이동, 자르기 · ZIP. 카메라 확대와 도구 칩. 전체 과정 또는 한 단계만 반복 (첫 화면 · 사용법 창 · 안내 카드) |
| `dist/coach.js` | 단계별 안내 카드: 단계마다 질문하고("그림이 가로로 몇 개인가요?") 대답 버튼으로 다음 할 일 진행, 그 단계 애니메이션 반복 · 접기 기억 |
| `dist/autoalign.js` | 가이드 선 자동 맞춤 (바탕색과 다른 부분의 분포를 보고 그림 덩어리 가운데로) |
| `dist/export.js` | GIF · PPT 만들기 |
| `dist/vendor/` | gifenc(GIF, MIT) · PptxGenJS(PPT, MIT) — 필요할 때만 불러옴 |
| `dist/phone.js` | 휴대폰 세로: 아래 막대(이전 · 단계 진행 · 다음), 되돌리기를 화면 이동 줄로 |
| `dist/poster.js` | 포스터 분할 인쇄: 종이 · 방향 · 가로 장수 → 세로 장수 자동, 프린터 여백(여백 없는 인쇄 불필요) · 풀칠 영역 · 자르는 선 · 장 번호, 붙이는 방법 안내 장, PDF 직접 작성 |
| `dist/sheet.js` | 자동 인식 학습지: 이모티콘 학습지 견본(PDF · PNG), 네 모서리 기준 마커(파인더 패턴 3 + 정렬 패턴 1) 찾기 → 원근 보정 → 12칸 영역 자동 배치, 다 그린 예시 사진 |
| `dist/landing.js` | 첫 화면 활용 사례 배경 · 카드, 예시 학습지 생성, 화면 전체 끌어 놓기 |
| `dist/brand/wsns-mark.svg` | WSNS 정사각형 로고 (WesNS 레포 `public/brand`와 같은 파일) |
| `dist/fonts/` | Pretendard · JetBrains Mono (OFL) |
| `verify*.cjs` | 회귀검사 |

## 배포

`main`에 푸시하면 `.github/workflows/pages.yml`이 검사를 통과한 뒤 `dist`를 GitHub Pages에 배포합니다. 레포 **Settings → Pages → Source: GitHub Actions**가 켜져 있어야 합니다.
